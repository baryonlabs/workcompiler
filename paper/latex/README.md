# LaTeX build

```bash
tectonic main.tex     # ACL two-column (review mode); tectonic auto-runs bibtex reruns
```

`acl.sty` / `acl_natbib.bst` are the official files from
github.com/acl-org/acl-style-files (repo root, master). `refs.bib` authors marked
`[authors TBD]` must be completed from the arXiv pages before submission
(titles/IDs are already abstract-verified).
