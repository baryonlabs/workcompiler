# OpenWorkLang specification

- **[baryonlabs/openworklang — SPEC.md](https://github.com/baryonlabs/openworklang/blob/main/SPEC.md)** (vendored here at [`vendor/openworklang/SPEC.md`](../vendor/openworklang/SPEC.md))
